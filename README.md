# RuFreedom 0.0.1

Локальный обход DPI-блокировок для Windows — по подобию **zapret** и **GoodbyeDPI**,
со стильным графическим приложением. Даёт доступ к заблокированным через DPI
сервисам: **Telegram, Discord, игровые серверы** (Fortnite, Apex, PUBG, Rockstar/GTA,
Steam, Valorant/Riot, Battle.net, Genshin/HoYoverse, Destiny, Path of Exile, EVE,
Final Fantasy XIV, Warframe и многие другие), **игровым CDN/сетям**,
**стримингу** (YouTube, Twitch) и **нейросетям**.

Работает **без VPN и прокси**: трафик идёт напрямую, движок «разрезает» первый
пакет соединения так, чтобы DPI не прочитал имя сайта/сервера. Поддерживает
**TCP (HTTP/HTTPS)** и **QUIC (HTTP/3 поверх UDP)**.

> ⚠️ Инструмент для обхода интернет-цензуры. Он меняет **только ваши собственные
> исходящие пакеты** и не перехватывает чужой трафик.

## Как это работает

Блокировки по DPI срабатывают на имя хоста в первом пакете соединения:
- **HTTPS (TCP/443)** — поле **SNI** в TLS ClientHello;
- **HTTP (TCP/80)** — заголовок **Host**;
- **QUIC (UDP/443)** — SNI внутри QUIC Initial.

Через драйвер **WinDivert** RuFreedom перехватывает этот пакет и:
- **TCP** — режет его на сегменты так, чтобы имя оказалось «на стыке» (DPI без
  пересборки TCP теряет имя, сервер собирает по seq-номерам нормально);
- **QUIC** — по умолчанию гасит QUIC Initial, и приложение откатывается на
  TLS-поверх-TCP, где уже работает разрезание.

### Техники TCP (`strategy`)
- **split** — разрезать первый пакет на 2 сегмента.
- **disorder** *(по умолчанию)* — то же + отправить сегменты в обратном порядке.
- **fake** — перед реальными данными послать «фальшивый» сегмент.
- **fakedisorder** — fake + обратный порядок (сильно против «умного» DPI).
- **multisplit** / **multidisorder** — разрезать на 3 сегмента (в т.ч. в обратном порядке).

Способ обмана фальшивого сегмента (`fooling`): **ttl** (низкий TTL — не доходит
до сервера), **badsum** (неверная TCP-чексумма — сервер отбрасывает), **none**.

### Режимы QUIC (`quic_mode`)
- **drop** *(по умолчанию)* — гасить QUIC → откат на TCP (надёжно).
- **ipfrag** — разбить QUIC Initial на два IP-фрагмента: DPI без пересборки
  фрагментов не видит SNI, а ОС-получатель собирает датаграмму обратно.
- **fake** — слать фальшивый UDP-пакет с низким TTL перед реальным.
- **off** — не трогать QUIC.

## Автоподбор обхода (вкладка ⚡ слева)
В 1 клик приложение само перебирает комбинации техник, для каждой реальным
TLS-подключением проверяет доступность набора сервисов (Discord, YouTube,
Telegram, Twitch, X, Instagram) и показывает, **какой обход работает лучше всего**.
Кнопка «Применить» сразу ставит найденную комбинацию на «Главной».
Нужны права администратора; во время подбора обход на «Главной» отключён.

## Один экземпляр
Повторный запуск не открывает второе окно: если RuFreedom уже работает,
существующее окно выносится на передний план (через именованный мьютекс).

## Интерфейс
- Тёмная панель на **всё окно** (без рамки).
- Слева — навигация: **Главная** (⌂) и **Автоподбор** (⚡).
- **Экран загрузки** в стиле хакерской консоли (быстро листающиеся команды +
  спиннер ⠋⠙⠹) при открытии и закрытии приложения.
- При наведении на кнопку запуска от неё **расходятся волны**; пока обход
  активен — волны анимируются постоянно.
- При наведении на меню «Стратегия TCP / QUIC / Fooling» и на «split_mode»
  в настройках — подсказка с описанием каждого способа (текущий помечен ▸).
- **Звук нажатия кнопок** — выбирается в настройках из списка (4 звука или
  «Без звука»), при выборе сразу проигрывается предпрослушка.
- **Статистика за сессию** (плитки сверху): время работы, число пакетов,
  объём обработанного трафика, число обходов DPI (TCP + QUIC).
- **Кнопка ⚙ (слева внизу)** открывает **отдельное окно настроек**: точка
  разреза имени (`split_mode`), TTL фальшивого пакета, звук кнопок,
  «сворачивать в трей при запуске», **автозапуск при включении ПК** и
  **история запусков**.
- Затухание окна при сворачивании в трей и при закрытии.

## Системный трей, профиль и история
- Закрытие окна (✕) **сворачивает приложение в трей**. По правому клику —
  «Открыть», «Включить/Выключить обход», «Выход».
- Настройки сохраняются в `config/settings.json` (рядом с `.exe` —
  `rufreedom-settings.json`) и восстанавливаются при запуске.
- При **выключении обхода** статистика сессии записывается в историю
  (`config/history.json`) и видна в окне настроек.
- **Автозапуск при включении ПК** — переключатель в настройках. Создаёт задачу
  в Планировщике Windows с правами «наивысшие» (через `schtasks`), чтобы
  RuFreedom стартовал при входе уже с правами администратора и обход работал
  сразу. Включение/выключение требует прав администратора.

## Про нейросети (важно)

DPI-обход снимает блокировку **РКН** (когда имя сервиса режет ваш провайдер).
Но многие AI-сервисы (OpenAI/ChatGPT, Google Gemini и др.) дополнительно
**блокируют по российскому IP на своей стороне** («not available in your country»).
Это геоблок, и его разрезание пакетов **не снимает** — нужен VPN/прокси для смены
IP. Домены AI добавлены: где режет РКН — заработает; где геоблок по IP — нет.

## Требования
- Windows 10/11, Python 3.8+
- Права администратора (нужны WinDivert)

> **Если приложение не открывалось раньше:** команда `python` в Windows часто
> указывает на «заглушку» из Microsoft Store, которая ничего не запускает.
> Лаунчеры теперь сами находят рабочий интерпретатор, поэтому просто запускайте
> их заново.

## Запуск

**Дважды кликните `start.bat`** — он найдёт рабочий Python, запросит права
администратора, поставит зависимости (`pydivert`, `customtkinter`, `pystray`,
`pillow`) и откроет приложение. GUI запускается через `pythonw` **без окна
консоли** — чёрное окно больше не висит снизу.

### Сборка в один .exe
Запустите **`build-exe.bat`** — получится самодостаточный `dist\RuFreedom.exe`
с иконкой, запросом прав администратора (UAC) и вшитым драйвером WinDivert.
Python и зависимости конечному пользователю уже не нужны.

Консольный режим — `start-console.bat` или вручную:
```powershell
pip install -r requirements.txt
# консоль от имени администратора:
python rufreedom.py
python rufreedom.py --strategy fake --quic fake --fake-ttl 5
python rufreedom.py --all              # обход для всего трафика
```

## Настройка

GUI настраивается переключателями. Для CLI — `config\rufreedom.ini`:

| Параметр        | Назначение |
|-----------------|------------|
| `ports`         | Порты перехвата TCP (`80, 443`) |
| `strategy`      | `split` / `disorder` / `fake` |
| `split_mode`    | `first-char` / `mid-host` / `host-start` / `host-end` |
| `quic_mode`     | `drop` / `fake` / `off` |
| `fake_ttl`      | TTL фальшивого пакета (3–8, подбирается) |
| `hostlist_path` | Файл доменов; пусто = весь трафик |

Домены сгруппированы в `dpi/services.py` (категории для GUI) и выгружены в
`config/hostlist.txt` (для CLI). Поддомены подхватываются автоматически.

## Если не помогло
1. Смените стратегию: `disorder` → `fake` и подберите `fake_ttl` (3, 4, 5, 6…).
2. Поставьте `quic_mode = fake` или `drop`.
3. Смените `split_mode` на `mid-host`.
4. Проверьте, что сервис есть в списке, или включите «Весь трафик».
5. Разные провайдеры — разный DPI; рабочая комбинация подбирается опытным путём.
